# TechStart Digital Ecosystem

A comprehensive digital ecosystem integrating Frontend Web Development (SPT1), System Integration & APIs (WS101), and Mobile App Prototyping (SPT2) into a unified startup solution.

## 🚀 Project Overview

This project demonstrates a complete digital ecosystem with:
- **Interactive Profile Website** with JavaScript features
- **Secure Login System** with Google OAuth 2.0 and quiz certification
- **Dynamic Product Showcase** with XML/JSON data and real-time pricing
- **Mobile App Prototype** walkthrough and demonstration
- **Unified Navigation** connecting all components seamlessly

## 📁 Project Structure

```
TechStart-Digital-Ecosystem/
├── index.html              # Main HTML file
├── styles.css              # CSS styles and animations
├── script.js               # Main JavaScript functionality
├── products.js             # Product management system
├── products.xml            # XML product data with DTD
├── products.dtd            # XML Document Type Definition
├── products.json           # JSON product data
└── README.md               # Project documentation
```

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Local web server (optional, for XML loading)

### Installation
1. Clone or download the project files
2. Open `index.html` in a web browser
3. For full XML functionality, serve from a local web server

### Usage
1. **Home Page**: Navigate between SPT1, WS101, and SPT2 sections
2. **Profile Section**: Interact with skill animations and contact form
3. **Login System**: Test authentication and quiz functionality
4. **Product Showcase**: Browse products with filtering and search
5. **Mobile App**: Experience the prototype walkthrough
